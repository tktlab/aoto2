# AOTO — たまごクエスト

中学1年生向けに、既存の `aoto`(Codexで作成)を「ゲーム感覚で続けられる」形に作り直した版です。
元の `aoto` フォルダは変更していません。

## 使い方

- **PC**: `start.cmd` をダブルクリック(または `index.html` を開く)。インストール不要、ログイン不要。
- **スマホ**: フォルダごと Vercel / Netlify / GitHub Pages などに置くと、そのまま静的サイトとして動きます。
  学習記録は端末のブラウザ(localStorage)に保存されます。

## 何が変わったか

| 既存 aoto | 新版 |
| --- | --- |
| ログイン・診断が入口 | 開いたらたまごがいて、ボタン1つで始まる |
| 点数・正答率中心 | ごはん → たまごが育つ → ずかんに仲間とカードが増える |
| 保護者/管理者画面が別ロール | 「おとなのへや」(ホーム下の「おとなの人へ」を長押し) |
| 前提に戻る説明は問題の途中から | 全画面に「😵 わからない」。ボタンだけで前提までさかのぼる |

### 「わからない」の流れ

1. 問題で「わからない」を押す。
2. 一度に1つずつ、声(端末の読み上げ)と動く図で説明。
3. 「わかった!たしかめる」→ 小さな確認。まだなら「🪜 もっとやさしく」で前提へ(分かれるときは「どこがわからない?」と選ぶ)。
4. 確認に正解すると1段ずつ上に戻り、最後は元の問題へ。画面上部のはしごで「いまどこまで戻っているか」が見える。

### ゲームの決まり

- 自力で正解 ごはん+2 / ヒントや説明のあと正解 +1 / 前提の確認に正解 +1。間違いや「わからない」で減点はありません。
- ごはん 3 でたまごにひび、8 で誕生、14 でずかんに登録され、次のたまごが来ます(仲間は12種)。
- 単元ごとに ⭐ が貯まり、初めて解けると「カード」がもらえます(⭐1=解けた / ⭐2=自力で解けた / ⭐3=別の問題でも自力)。
- 連続日数は、1日おやすみしても途切れません。

## 教材について

問題 120 問・単元(スキル)40・前提つき説明 82・図 164 は、既存 aoto の登録教材をそのまま変換して使っています(`js/data.js`)。
再生成する場合は `tools/extract-content.ts`(aoto の `src/lib` を `lib/` にコピーし、`npx tsx` で実行)を参照してください。

# AOTO 設計メモ (2026-11-11)

目的: 勉強が苦手な中1の子が、毎日開きたくなり、分からないところを「ボタンだけ」でさかのぼって理解できること。

## 方針
- 勉強モードを前面に出さない: 開くと育成キャラ(たまご)がいる。ごはん=問題を解く、が唯一の入口。
- 罰なし: 間違い・「わからない」は減点せず、むしろ前提の確認でごはんが貰える。
- つまずきを遡る: 既存の前提グラフ(82概念)を「はしご」として見せ、1段ずつ戻って1段ずつ戻る。
- 声とアニメ: 端末の日本語読み上げ + SVG/CSS の動く図(数直線・分数の帯・文の役割・方位・地球儀 など12種)。
- 軽量: ログイン・サーバー不要の静的サイト。記録は localStorage。

## 既存 aoto からの再利用
スキル40(前提グラフ) / 問題120 / 説明82(意味・例・手順・確認・前提) / 図164 → `js/data.js`

## 大人向け
「おとなのへや」(長押しで開く): 日ごとの学習量・単元ごとの○×と「わからない」回数・最近の記録・バックアップ書き出し。

## 制約
- 声は端末の音声に依存(iPhoneの音質・発音は実機で要確認)。
- 記録は端末内のみ(端末を変えると引き継がれない。書き出しでバックアップ可)。
- 教材は現在の120問の範囲。単元の追加は `tools/extract-content.ts` か `js/data.js` へ。
